### `CHAR(n)` — fixed length

`CHAR` always reserves **exactly `n` characters**.

```
name CHAR(10)
```

If you store:

```
"John"
```

the database treats it as a 10-character value, effectively padding the remaining space:

```
"John      "
```

Good for values that are always the same length.
Examples: Country codes, state abbreviations, fixed-length IDs/codes
### `VARCHAR(n)` — variable length

`VARCHAR` stores **up to `n` characters**, using only the space needed for the actual value (plus some storage overhead).

```
name VARCHAR(10)
```

If you store:

```
"John"
```

it stores essentially:

```
"John"
```

rather than padding it to 10 characters.

| Feature | `CHAR(n)` | `VARCHAR(n)` |
|---|---|---|
| Length | Fixed | Variable |
| Storage | Always `n` characters | Only the characters needed |
| Maximum length | `n` | `n` |
| Best for | Fixed-size values | Variable-size text |
| Example | `CHAR(2)` for country codes | `VARCHAR(100)` for names |
