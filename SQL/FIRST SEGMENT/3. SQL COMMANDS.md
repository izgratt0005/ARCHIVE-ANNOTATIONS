SQL = the language used to communicate with a database
Think of a database as a place where information is organized into **tables**.
For example:

```
CUSTOMERS
--------------------------------
id | name       | age
1  | Alice      | 24
2  | John       | 30
3  | Maria      | 27
```

### DDL — Data Definition Language

```
CREATE
ALTER
DROP
```

DDL is about **the structure of the database**, not primarily the data inside it.
#### `CREATE`

Creates something in the database, such as a table.

```
CREATE TABLE customers (
    id INT,
    name VARCHAR(100),
    age INT
);
```

You're basically saying:
> "Create a table called `customers` with these columns."
#### `ALTER`

Changes the structure of something that already exists.
For example, adding a column:

```
ALTER TABLE customers
ADD email VARCHAR(100);
```

Now the table has an additional `email` column.
#### `DROP`
Deletes the database object itself.

```
DROP TABLE customers;
```

This removes the **table and its data**.
#### Easy way to remember DDL
**DDL = Define the structure**

```
CREATE → create structure
ALTER  → change structure
DROP   → remove structure
```

### DML — Data Manipulation Language

```
INSERT
UPDATE
DELETE
```

DML is about **changing the data inside existing tables**.
#### `INSERT`
Adds new data.

```
INSERT INTO customers (id, name, age)
VALUES (4, 'Peter', 22);
```

You're adding a new row.

```
id | name  | age
4  | Peter | 22
```

---
#### `UPDATE`
Changes existing data.

```
UPDATE customers
SET age = 23
WHERE id = 4;
```

Peter's age changes from 22 to 23.
**Very important:** `WHERE` determines which rows are changed.
Without a `WHERE`, you could update **every row**.

---
#### `DELETE`
Removes data from a table.

```
DELETE FROM customers
WHERE id = 4;
```

This removes Peter's row, but **the table itself still exists**.
That's an important difference:

```
DROP TABLE customers;
```

→ destroys the table.

```
DELETE FROM customers;
```

→ removes rows from the table.

### `SELECT` — Retrieving Data

The top-right of the image shows:

```
SELECT
```

This is used to **retrieve/query data** from the database.

For example:

```
SELECT name, age
FROM customers;
```

The database might return:

```
name   | age
Alice  | 24
John   | 30
Maria  | 27
```

You can also filter:

```
SELECT *
FROM customers
WHERE age > 25;
```

Meaning:

> "Give me all customers whose age is greater than 25."

### The "Data Query Language" Part

The image calls `SELECT` part of:

**DQL — Data Query Language**

You may see different classifications depending on the SQL documentation/course:

```
DDL = Data Definition Language
DML = Data Manipulation Language
DQL = Data Query Language
```

For your notes, it's useful to associate:

|Category|Commands|Purpose|
|---|---|---|
|**DDL**|`CREATE`, `ALTER`, `DROP`|Define/change database structure|
|**DML**|`INSERT`, `UPDATE`, `DELETE`|Manipulate data|
|**DQL**|`SELECT`|Retrieve/query data|
### The Easiest Mental Model

Imagine you have a spreadsheet.
#### DDL = changing the spreadsheet's structure

```
CREATE → make a new spreadsheet/table
ALTER  → add/change a column
DROP   → delete the spreadsheet/table
```

#### DML = changing the information inside it

```
INSERT → add a row
UPDATE → modify a row
DELETE → remove a row
```

#### DQL = looking for information

```
SELECT → read/find data
```

So the image can essentially be reduced to:

```
                 SQL
                  │
       ┌──────────┼──────────┐
       │          │          │
      DDL        DML        DQL
       │          │          │
   CREATE      INSERT      SELECT
   ALTER       UPDATE
   DROP        DELETE
```

One thing to pay particular attention to as you're learning SQL: **`SELECT` reads data, while `INSERT`, `UPDATE`, and `DELETE` modify data.** That distinction becomes very important later when working with real databases.
